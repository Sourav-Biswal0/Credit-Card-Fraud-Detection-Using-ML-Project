# Credit Card Fraud Detection using Machine Learning

## 📌 Project Overview

Credit card fraud is one of the major security challenges in online transactions. Fraudulent activities can cause financial loss for customers and financial institutions.

This project uses Machine Learning classification algorithms to detect fraudulent credit card transactions by analyzing transaction patterns and predicting whether a transaction is genuine or fraudulent.

The goal of this project is to build a fraud detection system that improves transaction security and helps identify suspicious activity accurately.

---

## 🎯 Objectives

* Detect fraudulent credit card transactions using machine learning
* Analyze transaction data and identify fraud patterns
* Compare classification algorithms
* Evaluate model performance
* Improve fraud detection accuracy

## 📂 Dataset

The dataset contains credit card transaction records.

It includes:

* Transaction features
* Amount details
* Normal transactions
* Fraudulent transactions

Target column:

* **0 → Normal Transaction**
* **1 → Fraudulent Transaction**

## ⚙️ Project Workflow

### Step 1: Data Collection

* Imported credit card transaction dataset
* Loaded data into Jupyter Notebook

### Step 2: Data Preprocessing

* Checked dataset structure
* Verified missing values
* Cleaned data
* Split features and target values

### Step 3: Train-Test Split

* Divided dataset into:

  * Training Data
  * Testing Data

### Step 4: Model Training

Applied machine learning models:

### 1. Logistic Regression

* Used as baseline model
* Predicts fraud or non-fraud

### 2. Decision Tree Classifier

* Creates decision rules
* Detects suspicious transactions

### 3. Random Forest Classifier

* Combines multiple trees
* Improves prediction accuracy
